# 领域地图：Agentic Recommender Systems

## 1. 一句话定义
概念：Agentic Recommender System。
释义：把 LLM agent 放进推荐回路，使系统能规划、调用工具、维护记忆、多步交互，从静态排序转向目标驱动的推荐系统。
我的理解：关键不是LLM 能不能推荐，而是推荐系统能不能像 agent 一样作为一个助理自主规划部署一系列的工作。

## 2. 顶层 taxonomy：角色轴 × LoA 轴
概念：双轴分类法。
释义：角色轴描述 agent 在推荐回路中的位置；LoA 轴描述 agent 的自主性等级。
我的理解：三范式只属于角色轴；LoA 轴独立于三范式。但独立只是分类维度上的独立，同一个系统可以同时有角色和 LoA。

### 2.1 角色轴
- Agent-assisted recommender：辅助已有推荐 pipeline。
- Agent-as-recommender：agent 直接作为推荐决策者。
- Agent-as-user-simulator：agent 模拟用户或环境，生成反馈。

### 2.2 LoA 轴
- L0–L1：被动排序 / 静态 pipeline。
- L2：retrieval-grounded assistance。
- L3：tool-orchestrating assistance。
- L4：single-agent planning。
- L5：multi-agent orchestration。
- L6：概念上的 society of agents。
本综述重点：L2–L5。

## 3. 核心组件
- Profile：持久偏好与约束建模。
- Memory：working / episodic / semantic memory。
- Tool Use：RecTools、外部知识、属性工具、多模态工具。
- Workflow：ReAct、Plan-then-Execute、Reflex。
- Optimization：self-reflection、feedback-reflection。

## 4. 评估
概念：trajectory-level evaluation。
释义：评估对象从单一 ranked list 变成完整轨迹：用户输入、内部状态、动作、工具观察、输出、反馈。
我的理解：不能只看 NDCG，还要看整个系统的中间工作状况如何，如交互、grounding、工具、记忆、安全、成本。
- Target：推荐结果、交互、生成、grounding、simulator、agent trace、部署。
- Protocol：offline、simulation、user study、LLM-as-judge、red teaming、online。
- Metric：NDCG、Success@K、faithfulness、tool-selection accuracy、latency、token cost 等。

## 5. 开放挑战
- Modeling：终身用户建模、上下文抽象、多模态对齐。
- User：可控性、可解释与可信、隐私。
- System：可扩展性、训练与推理效率、API/交互效率。
